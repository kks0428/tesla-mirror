# MVP Spec

## 목표
사용자가 안드로이드 앱을 실행하고 Tesla 브라우저에서 접속하면, 폰 화면이 저지연으로 표시된다.

## 필수 기능
1. 안드로이드 화면 캡처 시작/중지
2. Tesla 브라우저 연결
3. 비디오 송출
4. 연결 상태 표시
5. 해상도 선택
6. bitrate 조절
7. 지연 측정

## 비필수 기능
- 오디오
- 터치 제어
- 자동 연결
- Shizuku 연동

## 사용자 흐름
1. 앱 설치
2. 화면 캡처 권한 허용
3. 앱이 세션 URL 또는 페어링 코드 표시
4. Tesla 브라우저에서 접속
5. 실시간 화면 확인

## 성공 기준
- 초기 연결 10초 이내
- 지연 체감 500ms 이하 목표
- 720p 기준 안정 송출
- 앱 백그라운드 전환 시 foreground service 유지

## 기술 가설
- Tesla 브라우저에서 WebRTC 재생 가능
- H.264가 가장 호환성이 높음
- signaling은 매우 단순하게 시작 가능

## 첫 실험 항목
1. Tesla 브라우저 WebRTC 수신 가능 여부
2. Tesla 브라우저 H.264 디코딩 안정성
3. 화면 회전 시 세션 유지 여부
4. 모바일 네트워크보다 로컬 핫스팟 환경이 더 적합한지 검증
