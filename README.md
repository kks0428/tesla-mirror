# Tesla Mirror

Tesla 브라우저에서 안드로이드 화면을 저지연으로 보는 앱 프로젝트.

## 목표
- 안드로이드 폰 화면을 Tesla 브라우저에서 본다
- 초기 목표는 저지연 영상 송출
- 이후 터치 입력, 오디오, 자동 연결을 추가한다
- 고급 권한 기능은 Shizuku 확장 계층으로 분리한다

## 제품 방향
- 코어: 안전한 미러링 앱
- 확장: Shizuku 기반 고급 자동화
- 목표 전송: WebRTC
- 프로토타입: 더 단순한 경로로 빠르게 검증 가능

## 1차 범위
- Android MediaProjection 기반 화면 캡처
- H.264 인코딩
- Tesla 브라우저용 웹 클라이언트
- 세션 연결, 해상도, bitrate 조절
- 지연 측정 및 기본 상태 UI

## 제외
- 초기에 root 의존 기능
- 초기에 WRITE_SECURE_SETTINGS 의존 기능
- 초기에 시스템 입력 완전 주입

## 디렉토리 계획
- docs/ : 설계 문서
- android/ : 안드로이드 앱
- web/ : Tesla 브라우저 클라이언트
- proto/ : 통신 프로토콜 초안
